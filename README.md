# 📱 Spendify

**Spendify** is a sleek, intuitive personal finance and expense tracking application built with **Flutter**.

---

## ✨ Features

- 💡 **Expense & Income Tracking:** Easily log and categorize your daily transactions.
- 📊 **Visual Analytics:** View spending insights and budget breakdowns.
- 🔐 **Privacy First:** All data is stored locally on your device.
- ⚡ **Cross-Platform:** Built to run smoothly on Android.

---

## 🚀 Built With

- **Flutter** & **Dart**
- **Android (Kotlin DSL)**
